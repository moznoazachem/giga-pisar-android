# Гига Писарь

Гига Писарь - Android-приложение для локального голосового ввода на русском языке. Приложение записывает речь с микрофона, распознаёт её на устройстве с помощью модели GigaAM и либо копирует результат в буфер обмена, либо вставляет его в активное текстовое поле.

Распознавание работает локально благодаря загруженной при первом запуске приложения модели. Аудиозапись не отправляется на удалённые серверы.

Выражаю отдельную благодарность автору оригинального репозитория [giga-pisar](https://github.com/moznoazachem/giga-pisar), благодаря которому стало возможным появление данного проекта.

## Возможности

- локальное распознавание речи через ONNX Runtime и GigaAM;
- режим «Буфер обмена»: по окончании голосового ввода текст вставляется в буфер обмена;
- режим «Текстовое поле»: по окончании голосового ввода текст вставляется в активное поле ввода;
- запуск записи удержанием кнопки уменьшения громкости;
- возможность скрыть виртуальную кнопку записи в настройках приложения;
- автоматическая очистка буфера после успешной вставки в поле ввода;
- загрузка и проверка модели по размеру, SHA-256 и vocabulary;
- поддержка Android API 24+.

## Запуск

Приложение можно собрать вручную, используя инструкцию ниже, или загрузить на устройство актуальную релизную [версию](https://github.com/moznoazachem/giga-pisar-android/releases/latest).

## Примечания

На некоторых прошивках (MIUI/HyperOS, OriginOS, ColorOS, EMUI и др.) действуют агрессивные механизмы энергосбережения, ограничивающие работу приложений в фоне. Из-за этого сервис специальных возможностей может самопроизвольно отключаться после сворачивания приложения или блокировки экрана.

Если возникла такая проблема, рекомендуется:
- разрешить приложению работу в фоновом режиме и автозапуск в настройках системы;
- отключить ограничения по энергопотреблению (выбрать режим «Без ограничений» или «Не экономить заряд» для приложения);
- закрепить приложение в списке недавних (запущенных) задач.

## Требования для разработки

- JDK 17;
- Android SDK с API 36;
- Gradle Wrapper из репозитория;
- устройство или эмулятор с Android API 24+;
- около 225 МБ свободного места для модели;
- разрешение на микрофон;
- включённый сервис специальных возможностей.

## Сборка

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/moznoazachem/giga-pisar-android
cd giga-pisar-android
```

Соберите debug APK:

```bash
./gradlew assembleDebug
```

Установите его на подключённое устройство:

```bash
android run --apks=app/build/outputs/apk/debug/app-debug.apk
```

или

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

После запуска приложения:

1. разрешите доступ к микрофону;
2. включите сервис «Гига Писарь» в настройках специальных возможностей;
3. скачайте модель GigaAM;
4. выберите режим вставки;
5. используйте плавающую кнопку микрофона или удерживайте кнопку уменьшения громкости, затем отпустите её для распознавания.
